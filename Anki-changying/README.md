# Anki 卡片更新中心

欢迎来到 **Anki 卡片更新中心**。

这里集中发布我所有在售牌组的：

- 🟢 **更新日志**：新牌组上线、内容增补、功能优化的正式记录
- 🔴 **勘误日志**：已有牌组中发现的错误、修正说明，保障你手上的卡片始终准确

---

## 如何使用

1. 左侧「更新日志」查看各牌组的新增与迭代；
2. 左侧「勘误日志」查看需要你注意的修正（建议订阅/定期回看）；
3. 顶部搜索框可直接搜牌组名、关键词（如「27红宝书」「发音」）。

> 提示：本站的每一次内容更新都会自动同步上线，无需你手动操作。
> 如果你是从淘宝/闲鱼购买的牌组，遇到内容与本站记录不一致，请以**勘误日志**为准。

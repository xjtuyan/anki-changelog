# 长缨记忆卡 · 更新与勘误中心

欢迎来到 **长缨记忆卡** 官方站点。这里集中发布我所有在售牌组的：

- 🟢 **更新日志**：新牌组上线、内容增补、功能优化的正式记录
- 🔴 **勘误日志**：已发布牌组中发现的错误与修正说明，保障你手上的卡片始终准确

## 站内导览

- 🛍️ [产品展示](/products) —— 按品类浏览全部牌组
- 📝 [更新日志](/changelog/2026-09) —— 看每一次迭代

## 如何使用

1. 在「产品展示」找到你需要的牌组；
2. 「更新日志」查看是否出了新内容、要不要补；
3. 「勘误日志」定期回看，按说明修正手上的卡。

> 本站每次内容更新都会自动同步上线，无需你手动操作。
> 如果你是从淘宝 / 闲鱼购买的牌组，遇到内容与本站记录不一致，请以**勘误日志**为准。
